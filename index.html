Cara Mendapatkan Client ID Google?

  2. Buat Project baru & aktifkan **Google Drive API**.
  3. Di menu **Credentials**, buat **OAuth 2.0 Client ID** (Web application).
  4. Tambahkan domain website kamu di **Authorized JavaScript origins**.
  5. Salin Client ID dan tempelkan pada kolom di atas.
